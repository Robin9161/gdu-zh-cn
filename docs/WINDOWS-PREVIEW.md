# Windows 中文预览版

本分支提供源码预览，用于本机磁盘分析与人工核对清理。它不是无人值守清理工具，也不会自动清空回收站。新增回收、扫描选择和扫描记录功能仅在 Windows 本地回环监听的 `--web-recycle-only` 模式下开放。

## 本次扩展

- 类别条形图、大小与修改时间散点图、联动清单及勾选合计。
- A/B/C/D 分级；类别和等级联合筛选；C 逐项选择，D 服务端拒绝。
- 目录或项目/软件归属汇总，按实际占用排序，并显示识别依据及清理影响。
- 先预览清单再确认回收；文件身份、大小、修改时间、真实路径和保护规则重新核对。
- 本地盘符/目录选择、重新扫描与取消；失败时保留可用的原结果。
- 最近一次扫描保存/恢复、原扫描时间展示、浏览偏好恢复。

架构决策见 [ADR 0004](adr/0004-cleanup-ownership-and-scan-snapshots.md)。保留上游 Go 模块路径，以维持内部导入和现有构建方式；仓库的中文扩展说明不代表上游背书。

## 验证范围

Windows 上验证了前端交互、分组和筛选、清理预览保护、扫描切换、保存覆盖、损坏记录回退、启动恢复与显式重扫。大型磁盘实机保存/重启恢复后，文件数量、占用及归属组数一致。没有把用户真实文件作为清理验收对象。

自动测试的回收后端使用替身，覆盖计划、身份变化和保护规则。正式发布可下载清理版前，仍需在隔离 Windows 环境验收真实回收、还原和不支持回收站的卷。当前不会据此声称所有 Windows 存储设备均已验证。

`preview-checks.yml` 对中文分支运行前端检查、Linux Go 测试和 Windows 相关测试。Windows 相关测试明确排除三个已用上游原版复现的问题：

- `TestReadAnalysis`：测试预期 Unix 路径分隔符。
- `TestAnalyzePathWithSummarizeFromSqliteStorage`、`TestAnalyzePathWithDepthFromSqliteStorage`：测试结束清理仍被占用的 SQLite 临时文件。

这些排除项不影响新增保护/快照用例运行，也不等于上游全套 Windows 测试通过。

## 已知限制

- Windows 上游扫描器的普通文件占用通常按文件大小估算；硬链接去重和分配单元统计存在限制。界面的占用指标不应当作精确可释放空间。
- 文件核对使用身份、大小及修改时间，不做内容哈希；初次扫描时间精度与路径型 Shell 操作也有边界，无法保证识别所有并发改写。
- 全盘扫描的内存需求随文件数量增长；在进程中恢复另一份记录时可能同时持有两棵树。
- 扫描可能跳过无权限目录，统计代表扫描可见范围。
- 归属根据路径和项目标记推断，不检测应用是否运行，也不证明依赖能够重新下载。
- 当前只保留最近一份记录。恢复结果是历史数据，界面会显示扫描时间。
- 目录分组与归属分组是两个视图；切换后以界面显示的文件范围为准。
- 回收站受卷类型、系统设置和文件状态影响；不支持时返回错误，不回退为永久删除。
- 扫描记录、启动令牌、真实路径截图和日志应留在本地，不上传到公开问题或仓库。

## 后续优先级

1. **真实回收与还原的隔离验收**：正式二进制发行前补齐 Windows 存储边界。
2. **扫描效率**：增量更新、限制峰值内存、保存/恢复的大任务反馈与取消。
3. **历史对比**：展示新增占用和增长最快目录，支持多份记录与保留策略。
4. **归属准确性**：完善虚拟环境、软件安装目录和项目规则，支持用户纠正归属。
5. **针对性清理**：收藏/排除目录、按年龄和体积组合过滤，以及重复文件审核；不自动删除唯一副本。
